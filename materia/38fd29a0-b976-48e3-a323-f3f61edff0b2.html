Mercado eleva previsão para inflação e dólar em 2027, diz Boletim Focus

247 - A inflação esperada pelo mercado financeiro para 2027 voltou a subir, enquanto a estimativa para o dólar no fim do próximo ano também avançou, segundo o Boletim Focus divulgado nesta segunda-feira (24). A projeção para o IPCA de 2026, por outro lado, foi mantida em 5,02% pela segunda semana consecutiva. Para 2027, a estimativa para o IPCA passou de 4,24% para 4,25%. A mudança foi pequena, mas indica nova revisão para cima na inflação esperada no próximo ano. Já para 2028, a projeção permaneceu em 3,80% pela quarta semana seguida. Para 2029, a expectativa ficou em 3,50%, patamar mantido pela 51ª semana consecutiva. No câmbio, o mercado manteve a previsão de dólar a R$ 5,20 no fim de 2026 pela décima semana consecutiva. Para 2027, no entanto, a estimativa subiu de R$ 5,29 para R$ 5,30. As projeções para os anos seguintes ficaram estáveis: R$ 5,30 em 2028, pela quinta semana consecutiva, e R$ 5,36 em 2029. A projeção para o crescimento do Produto Interno Bruto (PIB) em 2026 teve nova redução, passando de 1,98% para 1,95%. Para 2027, a estimativa foi mantida em 1,50%. O mercado elevou a previsão para 2028, de 1,89% para 1,98%, enquanto a expectativa para 2029 permaneceu em 2% pela 75ª semana seguida. Entre os demais indicadores de inflação, o Focus mostrou queda nas estimativas para o IGP-M. A previsão para 2026 recuou de 4,71% para 4,55%. Para 2027, passou de 4,10% para 4,09%, após três semanas consecutivas de baixa. A estimativa para 2028 caiu de 3,93% para 3,92%, e a de 2029 recuou de 3,85% para 3,83%. Também houve ajustes nas projeções para os preços administrados. Para 2026, a estimativa caiu de 4,70% para 4,69%, no quarto recuo semanal seguido. Para 2027, passou de 3,87% para 3,86%, após duas semanas de queda. Em 2028, porém, a previsão subiu de 3,56% para 3,60%, na segunda alta consecutiva.
