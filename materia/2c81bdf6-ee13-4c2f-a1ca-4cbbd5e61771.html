Sergipe lidera participação feminina nas eleições

Sergipe apresenta, nas eleições deste ano, o maior percentual de candidaturas femininas entre os Estados brasileiros, segundo levantamento do Tribunal Regional Eleitoral de Sergipe (TRE-SE). Do total de candidaturas registradas no Estado, 38,97% são de mulheres, conforme os dados divulgados pela Justiça Eleitoral.

O percentual considera os registros apresentados para os diferentes cargos em disputa nas eleições deste ano. Das 408 candidaturas registradas no estado, 159 são de mulheres, o que corresponde a 38,97% do total. As candidaturas masculinas somam 249, ou 61,03%.

Sergipe: dados das candidaturas

A participação feminina é calculada a partir do conjunto de candidaturas registradas, incluindo os diferentes cargos que serão disputados nas eleições. O percentual não representa a proporção de mulheres eleitas, mas apenas a composição das candidaturas apresentadas.

Os dados fazem parte das informações eleitorais disponibilizadas pela Justiça Eleitoral para o pleito de 2026. Em Sergipe, 1.740.240 eleitores estão aptos a votar, distribuídos pelos 75 municípios do Estado.

A Justiça Eleitoral mantém disponíveis as informações sobre candidaturas e registros eleitorais por meio do sistema de divulgação de dados das eleições. Os números podem sofrer alterações enquanto houver análise de registros e decisões judiciais relacionadas às candidaturas.

O TRE-SE também disponibiliza uma página específica para as Eleições 2026, com informações sobre registros de candidatura, federações partidárias, legislação eleitoral, pesquisas e demais dados do pleito.
